三步跑起来

OPC Agent 本身不含模型，它负责把你本机已有的 Agent 组织起来。正式下载入口待 GitHub 仓库确认后开放。

使用前提：本机需要已安装并登录至少一个 Agent CLI（推荐 codebuddy login）。如果你还没有凭据，应用能装能开，但发消息会提示未授权 —— 这是设计如此，不是安装失败。

你可能想先知道这些

Windows 提示「已保护你的电脑」或「未知发布者」，怎么办？

这是 Windows SmartScreen 对未做代码签名程序的默认提示。个人开发者签名证书一年需要数千元，本项目没有购买。

处理方式：点击提示框里的「更多信息」，再点「仍要运行」。或者右键安装包 → 属性 → 勾选「解除锁定」→ 确定，再双击运行。

为什么装完了发消息没反应？

OPC Agent 不内置模型，它调用的是你本机已经装好并登录的 Agent。请先在终端执行 codebuddy login（或配置对应 Agent 的 API Key），然后重启应用。

如果左侧通讯录是空的，说明本机没有检测到任何 Agent CLI，需要先安装其中一个。

安装版和便携版有什么区别？

安装版（-setup.exe）走 NSIS 安装，支持后续自动更新，推荐使用。

便携版（-portable.exe）免安装、可放 U 盘，但无法自动更新 —— 有新版本时需要手动下载替换。

我的聊天内容会被上传吗？

不会。会话记录、生成图片、Agent 配置都保存在本机数据目录，不上传任何服务器。

当前公开构建没有配置统计端点，也不会发送使用统计 —— 代码里不存在遥测模块。详见隐私说明。

支持 macOS 或 Linux 吗？

目前只发布 Windows x64 安装包。代码本身是跨平台的 Electron 应用，理论上可以自行在 macOS / Linux 上构建，但没有官方构建产物，也未做完整验证。

可以自己编译吗？

可以，仓库里就是完整源码。需要 Node.js 22+，克隆后执行 npm install，再 npm run electron:build 出包。

构建细节和已知的环境坑写在仓库的 DEVELOPMENT.md 里。
