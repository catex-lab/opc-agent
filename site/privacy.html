隐私说明

最后更新：2026 年 10 月 29 日

一句话：聊天记录、文件和 Agent 凭据全部保存在本机。应用不收集任何信息 —— 没有使用统计、没有埋点、没有崩溃上报，也没有安装 ID；代码里不存在遥测模块。

1. 应用能做什么

OPC Agent 不是纯聊天窗口。为了替你执行任务，它需要调用一批系统能力。 下表列出每一项能力、用途，以及你可以怎么限制它 —— 这是使用前最该知道的部分。

能力用途默认状态怎么限制
读取本地文件 把项目文件作为上下文交给 Agent 仅限你选定的工作目录 不选工作目录，Agent 就无从读起
写入 / 修改文件 生成产物、改动代码 受权限门禁约束 权限门禁设为「每次确认」或「计划模式」
执行系统命令 跑构建、脚本、自动化流程 受权限门禁约束 同上；危险命令默认拦截
内置终端 你自己敲命令，不经过 Agent 手动开启 不使用终端面板即可
内嵌浏览器 预览网页、调试前端 手动开启 不使用浏览器面板即可
网络访问 调用你配置的模型 API 必需 关闭后应用无法工作

关键区别：文件写入与命令执行都受「权限门禁」约束，危险操作默认要你逐次确认。 这是本应用与「一键跑完所有事」类工具的分界线 —— 控制权留在你手上，而不是交给模型。

应用不会在后台偷偷截屏、录屏、读取剪贴板，也没有开机自启与常驻守护进程。

2. 我们收集什么

什么都不收集。应用不向任何服务器发送使用统计、崩溃报告或设备信息， 也没有安装 ID —— 这一条不是「默认关闭」，而是这个模块根本不存在。

会话内容只会发给你自己配置的模型服务商 —— 那是功能本身（不发给服务商，模型就无法回答）， 不是统计。应用不经过任何中转服务器，也没有自建后端。

另外两类网络请求都由你主动触发、且不携带任何会话内容：点「检查更新」时向 GitHub 查询版本号； 点开外链时交给系统浏览器打开。

3. 我们绝不收集

  • 聊天内容、提示词、模型的任何输出
  • 你打开的文件、文件路径、工作区目录结构
  • Agent 凭据、API Key、登录令牌
  • 原始 IP、设备指纹、精确地理位置
  • 任何第三方账号信息

会话数据库（chat.db）与生成图片缓存都存放在本机数据目录，不会上传到任何服务器。

4. 为什么不做统计

这是由个人维护的开源项目。做统计确实能知道有多少人在用、哪个版本还在被使用， 但这些信息不值得用「给每个用户装一个上报模块」来换。所以这个项目没有统计， 你也不需要去找一个开关把它关掉。

5. 怎么关闭

没有可关的东西。应用里没有统计开关，因为不存在统计。 「设置 → 关于与隐私」里只有版本信息、隐私承诺和官方入口。

6. 你的权利

没有任何数据被收集，所以没有需要撤回的授权，也没有需要申请删除的上报记录。 你仍然完全掌控本机的数据：

  • 删除本机数据：直接删除应用的数据目录即可。会话、图片、配置都在那里， 应用不依赖任何云端账号，删掉就是彻底删掉。
  • 审查代码：源码以 MIT 协议发布，不含任何遥测、埋点或崩溃上报的实现 —— 不是被关掉了，是没有写。
  • 断网使用：除了调用你自己配置的模型服务商，应用不需要任何外网连接。

7. 数据存在哪、留多久

只有本机数据目录一处。留存多久完全由你决定 —— 应用不做自动清理，也不上传备份。

8. 涉及的服务商

  • Cloudflare：托管本官网页面，按其自身隐私政策处理访问本站的网络层信息。
  • GitHub：托管源码与安装包下载，按其自身政策处理相应请求。
  • 你自己配置的模型服务商：只在你发消息时接收对话内容，受其自身条款约束。

9. 关于第三方 Agent

OPC Agent 本身不提供模型服务。你通过它调用的 WorkBuddy、Codex、Gemini、Claude Code 等 Agent 是各自厂商的产品，其数据处理方式（含各自的遥测与条款）由对应厂商决定，不在本说明的覆盖范围内 —— 本应用自身不发统计，不等于这些 Agent 自身也不发。

10. 未成年人

本项目不面向 14 周岁以下儿童，也不会收集其信息。

11. 变更通知

本说明如有修改，会更新页面顶部的日期。若将来某个构建引入了统计能力， 会在启用前更新本页并在应用内提供开关 —— 而不是先收集、再补说明。

12. 联系方式

对隐私有任何疑问，可在 GitHub 仓库（catex-lab/opc-agent）开 issue， 或通过官网联系项目维护者。

Privacy notice

Last updated: October 29, 2026

In short: Conversations, files and agent credentials stay on your machine. The app collects nothing — no usage analytics, no tracking, no crash reporting, no install ID. There is no telemetry module in the code.

1. What the app can do

OPC Agent is more than a chat window. To help you carry out tasks, it can use system capabilities. The table lists what each capability does and how you can limit it.

CapabilityPurposeDefaultHow to limit it
Read local filesProvide project files as context to an agentLimited to the workspace you selectDo not select a workspace
Write or modify filesCreate artifacts and change codeSubject to permission controlsRequire confirmation or use plan mode
Run system commandsRun builds, scripts and automationSubject to permission controlsSame controls; dangerous commands are blocked by default
Built-in terminalCommands you type yourself, outside the agentOpened manuallyDo not use the terminal panel
Embedded browserPreview web pages and debug front endsOpened manuallyDo not use the browser panel
Network accessCall the model or agent service you useRequired for agent requestsWithout it, agent requests cannot work

Key distinction: file writes and command execution are governed by permission controls; dangerous operations require confirmation by default. You retain control over these actions.

The app does not secretly take screenshots, record your screen, read the clipboard, start with Windows or run a background daemon.

2. What we collect

Nothing. The app sends no usage analytics, crash reports or device information to any server, and it has no install ID — this is not a setting that is switched off, the module does not exist.

Conversation content is sent only to the model provider you configured yourself — that is the feature itself, not analytics. There is no relay server and no backend operated by this project.

Two other network requests happen only when you trigger them, and neither carries conversation content: checking for updates queries GitHub for the version number; opening an external link hands it to your system browser.

3. What we do not collect

  • Conversation content, prompts or model output
  • Files you open, file paths or workspace structure
  • Agent credentials, API keys or sign-in tokens
  • Raw IP addresses, device fingerprints or precise location
  • Third-party account details

The conversation database (chat.db) and generated image cache stay in the local application data directory and are not uploaded by OPC Agent.

4. Why there is no analytics

This project is maintained by an individual. Analytics would tell us how many people use the app and which versions are still installed, but that is not worth shipping a reporting module to every user. So there is no analytics, and no switch to go looking for.

5. How to turn it off

There is nothing to turn off. There is no analytics switch in the app because there is no analytics. Settings → About & Privacy contains only version information, the privacy commitments and official links.

6. Your choices

No data is collected, so there is no consent to withdraw and no reported record to request deletion of. You still fully control the data on your machine:

  • Delete local data: Delete the application data directory. Conversations, images and configuration are stored there; OPC Agent does not require a cloud account.
  • Read the code: The source is released under the MIT licence and contains no telemetry, tracking or crash reporting — not disabled, simply never written.
  • Use it offline: Apart from calling the model provider you configured, the app needs no internet access.

7. Where data is stored and how long

Only in the local application data directory. How long it stays is entirely up to you — the app does not auto-delete and does not upload backups.

8. Service providers

  • Cloudflare: Hosts this website and processes network-layer information for visits under its own privacy policy.
  • GitHub: Hosts the source code and installer downloads under its own policies.
  • Your own model provider: Receives conversation content only when you send a message, under its own terms.

9. Third-party agents

OPC Agent does not provide model services. WorkBuddy, Codex, Gemini, Claude Code and other agents you use through it are products of their respective vendors, and their data practices — including their own telemetry and terms — are outside this notice. This app sending no analytics does not mean those agents send none.

10. Children

This project is not intended for children under 14, and it does not knowingly collect their information.

11. Changes

We update the date at the top of this page when the notice changes. If a future build ever introduces analytics, this page will be updated and an in-app switch provided before collection starts — not afterwards.

12. Contact

For privacy questions, open an issue on the GitHub repository (catex-lab/opc-agent) or contact the maintainer through the official website.
