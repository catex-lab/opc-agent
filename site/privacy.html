隐私说明

最后更新：2026 年 10 月 23 日

一句话：聊天记录、文件和 Agent 凭据保存在本机。当前公开构建没有配置统计端点，因此不会发送使用统计。 若未来某个构建启用了统计，还需用户开关允许才会上报列明的有限字段。

1. 应用能做什么

OPC Agent 不是纯聊天窗口。为了替你执行任务，它需要调用一批系统能力。 下表列出每一项能力、用途，以及你可以怎么限制它 —— 这是使用前最该知道的部分。

能力用途默认状态怎么限制
读取本地文件 把项目文件作为上下文交给 Agent 仅限你选定的工作目录 不选工作目录，Agent 就无从读起
写入 / 修改文件 生成产物、改动代码 受权限门禁约束 权限门禁设为「每次确认」或「计划模式」
执行系统命令 跑构建、脚本、自动化流程 受权限门禁约束 同上；危险命令默认拦截
内置终端 你自己敲命令，不经过 Agent 手动开启 不使用终端面板即可
内嵌浏览器 预览网页、调试前端 手动开启 不使用浏览器面板即可
网络访问 调用你配置的模型 API 必需 关闭后应用无法工作

关键区别：文件写入与命令执行都受「权限门禁」约束，危险操作默认要你逐次确认。 这是本应用与「一键跑完所有事」类工具的分界线 —— 控制权留在你手上，而不是交给模型。

应用不会在后台偷偷截屏、录屏、读取剪贴板，也没有开机自启与常驻守护进程。

2. 我们收集什么

当前公开构建的统计端点为空，客户端不会发送遥测请求。只有某个构建配置了统计端点，且用户没有关闭设置中的开关时，才可能发送以下字段：

字段示例用途
安装 ID随机 UUID区分独立用户，首次启动生成，与账号无关
启动时间时间戳计算日活、周活、月活
使用时长秒数了解单次使用时长分布
应用版本1.0.0判断哪些版本还在被使用
操作系统与架构win32 / x64决定后续优先支持哪些平台

如果未来部署下载统计 Worker，它可能记录下载次数、下载渠道与 Cloudflare 提供的国家/地区。目前该 Worker 尚未部署，因此站点不会记录这类下载统计。

3. 我们绝不收集

  • 聊天内容、提示词、模型的任何输出
  • 你打开的文件、文件路径、工作区目录结构
  • Agent 凭据、API Key、登录令牌
  • 统计记录不会存储原始 IP、设备指纹或精确地理位置；网站托管和 API 服务商可能按其政策处理网络层信息
  • 任何第三方账号信息

会话数据库（chat.db）与生成图片缓存都存放在本机数据目录，不会上传到任何服务器。

4. 为什么要收集

这是由个人维护的项目。若未来某个版本启用可选统计，有限的汇总数据可帮助了解使用情况和版本分布；统计可以关闭。

5. 怎么关闭

若当前版本配置了统计端点，打开应用 → 设置 → 关于与隐私 → 关闭「允许发送匿名统计」。关闭后立即停止，不会补发。端点未配置的版本不会发送统计。

也可以在启动应用前设置环境变量 OPC_TELEMETRY=0，或在数据目录的 analytics.json 里把 enabled 改成 false。

6. 你的权利

你随时可以行使以下权利，不需要经过任何审批流程：

  • 撤回授权：设置 → 关于与隐私 → 关闭「允许发送匿名统计」，立即生效，当前会话的收尾上报也会被拦住。
  • 删除本机数据：直接删除应用的数据目录即可。会话、图片、配置都在那里，应用不依赖任何云端账号，删掉就是彻底删掉。
  • 要求删除已上报的统计：统计使用随机安装 ID，不与 OPC 账号关联。若要申请删除，提供数据目录 analytics.json 中的 installId 联系项目维护者；正式支持渠道待仓库确认后公布。
  • 了解用途：本页列出了目前计划的全部统计用途；启用前会更新本说明。

拒绝统计不影响任何功能。关闭后应用与开启时完全一致 —— 我们不会用功能阉割来换取数据。

7. 数据存在哪、留多久

若未来启用统计，数据将存放在所部署的 Cloudflare D1 数据库中，由项目维护者管理。目前没有已部署的统计端点，也没有可供核验的线上留存与自动删除周期；启用收集前应配置并披露相应的删除安排。我们不会出售统计数据。

8. 涉及的服务商

  • Cloudflare：当前站点托管服务商。若未来部署下载分发和统计接口，它也可能提供相应服务，并按自身隐私政策处理网络层信息。
  • GitHub：正式仓库和下载尚未开放。配置后，源码托管与下载将由 GitHub 按其政策处理。

9. 关于第三方 Agent

OPC Agent 本身不提供模型服务。你通过它调用的 WorkBuddy、Codex、Gemini、Claude Code 等 Agent， 其数据处理方式由对应服务商的条款决定，不在本说明的覆盖范围内。

10. 未成年人

本项目不面向 14 周岁以下儿童，也不会主动收集其信息。

11. 变更通知

本说明如有修改，会更新页面顶部的日期。GitHub 仓库地址尚待确认，因此目前无法提供公开提交记录链接。应用内变更提示尚未实现，请以本页内容为准。

12. 联系方式

对隐私有任何疑问，可通过官网联系项目维护者。GitHub 仓库和 issue 地址待正式仓库确认后补充。

Privacy notice

Last updated: October 23, 2026

In short: Conversations, files and agent credentials stay on your machine. The current public build has no telemetry endpoint configured, so it sends no usage analytics. If a future build enables analytics, data is sent only when the in-app setting also allows it, and only for the fields listed below.

1. What the app can do

OPC Agent is more than a chat window. To help you carry out tasks, it can use system capabilities. The table lists what each capability does and how you can limit it.

CapabilityPurposeDefaultHow to limit it
Read local filesProvide project files as context to an agentLimited to the workspace you selectDo not select a workspace
Write or modify filesCreate artifacts and change codeSubject to permission controlsRequire confirmation or use plan mode
Run system commandsRun builds, scripts and automationSubject to permission controlsSame controls; dangerous commands are blocked by default
Built-in terminalCommands you type yourself, outside the agentOpened manuallyDo not use the terminal panel
Embedded browserPreview web pages and debug front endsOpened manuallyDo not use the browser panel
Network accessCall the model or agent service you useRequired for agent requestsWithout it, agent requests cannot work

Key distinction: file writes and command execution are governed by permission controls; dangerous operations require confirmation by default. You retain control over these actions.

The app does not secretly take screenshots, record your screen, read the clipboard, start with Windows or run a background daemon.

2. What we collect

The current public build has no telemetry endpoint configured and sends no analytics requests. Only a build configured with an endpoint, while the user has left analytics enabled, may send these fields:

FieldExamplePurpose
Install IDRandom UUIDDistinguish installations; not linked to an OPC account
Start timeTimestampCalculate daily, weekly and monthly active use
Session durationSecondsUnderstand session length distribution
App version1.0.0See which versions remain in use
Operating system and architecturewin32 / x64Prioritize platform support

If a download-tracking Worker is deployed, it may record download counts, channel and country or region supplied by Cloudflare. That Worker is not currently deployed for this project.

3. What we do not collect

  • Conversation content, prompts or model output
  • Files you open, file paths or workspace structure
  • Agent credentials, API keys or sign-in tokens
  • Raw IP addresses, device fingerprints or precise location in analytics records; hosting and API providers may process network-layer information under their own policies
  • Third-party account details

The conversation database (chat.db) and generated image cache stay in the local application data directory and are not uploaded by OPC Agent.

4. Why collect analytics

This is an open-source project maintained by an individual. If analytics is enabled in a future build, limited aggregate usage information can help understand adoption and identify which versions are still in use. Analytics is optional and can be disabled.

5. How to turn it off

If your build has a telemetry endpoint configured, open Settings → About & Privacy and turn off “Allow anonymous analytics”. Collection stops immediately and is not backfilled. A build without an endpoint sends no analytics.

You can also set OPC_TELEMETRY=0 before launch, or set enabled to false in analytics.json in the app data directory.

6. Your choices

You can exercise these choices without approval:

  • Withdraw consent: Settings → About & Privacy → turn off analytics. It takes effect immediately and blocks the session end event too.
  • Delete local data: Delete the application data directory. Conversations, images and configuration are stored there; OPC Agent does not require a cloud account.
  • Request deletion of reported analytics: Analytics uses a random install ID that is not linked to your identity. If you need a record removed, provide the installId from analytics.json to the project maintainer after a support contact becomes available.
  • Understand use: This page describes the purposes. There are no undisclosed analytics purposes.

Turning analytics off does not limit app features.

7. Where data is stored and how long

If analytics is enabled in the future, data will be stored in the Cloudflare D1 database configured by the project maintainer. No public telemetry endpoint is currently deployed, and there is no live retention or automatic deletion schedule to verify. A deletion schedule should be configured and disclosed before collection is enabled. We do not sell analytics data.

8. Service providers

  • Cloudflare: Hosts this website. If download delivery or analytics infrastructure is deployed later, Cloudflare may provide those services and process network-layer information under its privacy policy.
  • GitHub: The official repository and downloads are not yet available. Once configured, GitHub will handle source hosting and downloads under its own policies.

9. Third-party agents

OPC Agent does not provide model services. When you use WorkBuddy, Codex, Gemini, Claude Code or another agent, the selected provider processes your requests under its own terms and privacy policies. Those practices are outside this notice.

10. Children

This project is not intended for children under 14, and it does not knowingly collect their information.

11. Changes

We update the date at the top of this page when the notice changes. The official GitHub repository is still being confirmed, so a public commit history is not yet linked. In-app change notices are not implemented; please refer to this page.

12. Contact

For privacy questions, contact the project maintainer through the official website. The GitHub repository and issue tracker will be linked once the official repository is confirmed.
