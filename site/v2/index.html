FEATURES

一个人，带一支不眠的团队

不用记每个 CLI 的参数，也不用再开十几个终端窗口。Agent 不是配置项，是联系人。

Agent 通讯录

自动发现本机已安装的 Agent，头像、在线状态、未读红点一应俱全。装了什么就有什么，不需要手动登记。

多 Agent 群聊

把多个 Agent 拉进同一个群：同屏对话、横向对比、互相接力。五种编排模式决定谁先说、谁接手。

工作区面板

内置真 PTY 终端、浏览器与文件树：Agent 改了哪个文件、跑了哪条命令，当场可见，不用切窗口。

权限门禁

危险命令默认拦截，文件写入与命令执行可设为逐次确认。四档权限模式逐档落地，从不虚标。

会画图的联系人

生图 Provider 同样挂在通讯录里。生成的图片自动落盘缓存，历史消息里的图永远不会裂开。

本地优先

会话、图片、配置全部存在本机 SQLite。没有云端账号，删掉数据目录就是彻底删掉。

SCREENS

左边是谁，右边是它正在干什么

消息列表、对话区、工作区面板 —— 和你熟悉的 IM 一个布局，不需要重新学习。

使用前提

OPC Agent 不内置模型，它负责把你本机已有的 Agent 组织起来。请先在终端登录至少一个 Agent CLI（推荐 codebuddy login）。没有凭据时应用能装能开，但发消息会提示未授权 —— 这是设计如此，不是安装失败。

  2. 02

    登录你的 Agent

FAQ

你可能想先知道这些

Windows 提示「已保护你的电脑」，怎么办？

这是 SmartScreen 对未签名程序的默认提示 —— 个人代码签名证书一年数千元，本项目没有购买。点击「更多信息 → 仍要运行」即可；也可以右键安装包 → 属性 → 勾选「解除锁定」。

为什么装完了发消息没反应？

OPC Agent 不内置模型，它调用的是你本机已装好并登录的 Agent。先在终端执行 codebuddy login（或配置对应 Agent 的 API Key），再重启应用。通讯录是空的，说明本机没有检测到任何 Agent CLI。

安装版和便携版有什么区别？

功能完全一致。安装版（-setup.exe）支持自动更新与快捷方式，卸载时可选保留数据；便携版（-portable.exe）免安装、可放 U 盘，但不自动更新。

我的聊天内容会被上传吗？

不会。会话记录、生成图片、Agent 配置都保存在本机数据目录，不上传任何服务器。

当前公开构建没有配置统计端点，也不会发送使用统计 —— 代码里不存在遥测模块。详见隐私说明。

支持 macOS 或 Linux 吗？

目前只发布 Windows x64 安装包。代码本身是跨平台的 Electron 应用，可以自行构建（npm install 后 npm run electron:build），但没有官方产物，也未做完整验证。

「待接入」状态的联系人是什么意思？

通讯录按本机实际探测结果如实展示：没装、装了没登录、或该 Agent 暂无可用的无头调用方式，都会标出来并给出下一步指引。我们坚持「点得动的按钮才给点」。
