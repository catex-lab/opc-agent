# OPC Agent v1.0.14

本版集中收口界面的排印与交互细节：设置页按参考图重排、下拉改成自绘面板、双主题色阶统一到同一套框架面，聚焦与图标清晰度也一并钉成契约。没有破坏性改动，本地数据与升级路径不变。

## 改进

- **设置页按参考图重排**：主标签 14px/500、说明 11px，标签到说明 24px，行内上下 17px 加一条 1px 低对比分隔线；分区标题只保留 14px/600 文字，不再用 18px 标题块。控件改为填充式、高 36px、右沿与内容同线；聚焦只加柔和环，不再改边框或填充色。说明文字移入左列，与右侧控件垂直居中。

- **设置项下拉改为自绘面板**：原生 select 的展开菜单由系统绘制、边线过硬，改为自绘的 combobox + listbox（WAI-ARIA 完整），弹层用低对比描边与既有圆角/阴影令牌，键盘上下键与 Esc 可直接操作、读屏能读到选项名。取值、持久化 key 与后端契约不变；标题与下拉同一行，容器宽度 ≤360px 时自动改为上下堆叠。

- **双主题色阶重定**：亮暗两套色阶按同一套设计系统一次落定。暗色把标题栏 / 导航 / 列表统一到同一个框架面，收回导航条原先单独亮出的第三档，层级从四层回到「框架 / 内容 / 浮起」三层；亮色导航条并入框架面。两套文字的三档对比度重新计算，标签按新浮起面重算后仍不低于 4.5:1。

- **四档排版令牌**：新增标题、列表项、分区标题、提示四档语义字号令牌，落在面板栏标题、标题栏应用名等位置，后续排版不再各处手写字号。

- **设置弹窗层级校准**：设置页弹窗的面板回到浮起面，面板里的卡片与下拉选中再抬两档（新增 `--tc-surface-raised-2/-3` 语义令牌，不写死到组件），深色遮罩 0.34 → 0.52、亮色 0.34 → 0.26，弹窗与画布的明度差回到参考图水平（面板 / 遮罩 ΔL* 17.2，参考 17.3）。深色在线状态点提亮一档（6.93:1 → 9.16:1），亮色保持原值以守住 3:1 下限；状态区分仍只靠形状。

- **导航栏收窄、图标保持锐利**：栏宽 74 → 56px，按钮 44×46，图标盒 20px；缩放系数变成非整数后，导航图标改用 `non-scaling-stroke`，描边按 CSS 像素落屏（常态 2px / 选中 2.5px），边缘不发虚，也没有用透明度换缩小。

- **主题偏好卡片去掉图标色块**：三张卡里的图标改为纯线性单色，去掉外面那圈 36×36 的实心色块；选中态仍只由卡片描边与淡底表达，图标不因选中加色或加粗。

- **登录配置「刷新」收为次级按钮**：改为 30px 高的描边按钮（12px 字 / 13px 图标），描边走低对比令牌，悬停只抬底色不转品牌色，可访问性与热区保持。

- **聚焦描边统一契约**：输入框聚焦统一为 2px 中性环，去掉品牌色边框与双环；环色随亮/深主题各取一档，聚焦不再改边框色，悬停才提升描边对比。勾选框补回键盘专用聚焦环，错误态仍走红色边框。

## 需要注意

- 色阶与排版变化只影响视觉，取值与数据契约不变；自定义主题不会因此重置。

- 会话数据保存在 `%APPDATA%\opc-agent`，覆盖安装不受影响。
