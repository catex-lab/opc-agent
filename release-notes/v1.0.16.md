# OPC Agent v1.0.16

本版加了两个让界面更顺手的能力：左侧二级栏可以收起、界面支持中英切换；同时把 Agent 登录态判定改得更准，少一些「明明没登录却显示已就绪」的误判。没有破坏性改动，本地数据与升级路径不变。

## 新增

- **二级栏可以收起**：导航条底部新增折叠钮，收起后只保留 56px 图标栏，内容区自动补位。当前页没有可看内容（通讯录 / 项目 / 扩展未选中条目、没有选中会话）或窗口过窄时，按钮会置灰并说明原因，避免把唯一入口藏起来。收起状态会随偏好保存，缺省仍是展开，升级后界面与上一版一致。

- **中英切换，默认跟随系统**：导航栏、标题栏、设置页、通讯录、聊天页与设置子面板都支持中英文，也可以在设置页手动指定语言。

- **「回答语言」设置**：三档可选——自动 / 中文 / 英文。指定后回答按所选语言输出；选「自动」则沿用模型默认，不额外注入指令。

## 改进

- **登录态判定更准**：不再因为配置文件存在就判「已登录」，改为读取凭据里的过期时间。凭据过期但仍带刷新令牌的仍视为可用，首次使用会尝试自动刷新；确实需要重新登录的，会给出「怎么恢复」的指引。

- **「上一轮指令未完成」更轻**：确认改为一行 38px 状态条 +「查看处理」弹层，三个选项收进弹层；关闭只是收起，不替你做选择，刷新或切走再切回后状态仍然保留。

- **知识库入口去掉外框**：与其余三个头部入口统一为裸图标，点击热区不变。

## 需要注意

- 无破坏性改动，取值与数据契约不变；会话数据仍保存在 `%APPDATA%\opc-agent`，覆盖安装不受影响。

- 更新清单与代码包仍走签名校验，升级方式与上一版一致。
