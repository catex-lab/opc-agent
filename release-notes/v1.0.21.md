# OPC Agent v1.0.21

这一版主要修三处让人卡住的问题：WorkBuddy 登录来回弹浏览器、应用与桌面端抢同一份登录态、以及回答整段重复。顺带把回合状态指示器收小一档，并让 Codex / Claude 的运行组件改为按需下载。没有破坏性改动，本地数据与升级路径不变。

## 修复

- **回答不再整段重复**：WorkBuddy 偶尔会把同一条消息下发两次，此前界面把同一段正文拼接了两遍（CLI 侧只有一份，界面上却出现两份）。现在同一块内容重复到达只保留一份，正常续写不受影响。

- **登录不再来回弹浏览器**：以前后台探测遇到未登录时会自己拉起授权页，浏览器反复冒出来但应用始终显示「未登录」。现在登录流程只在你点「去登录」之后启动。

- **登录态与桌面端互不干扰**：应用内的 WorkBuddy 登录改为独立保存，登录与令牌刷新都写在自己的存储里，不再读取、也不改写桌面客户端的凭据。你可以在应用里登录而不影响桌面端，反过来也一样；恢复提示同步改成「登录态独立保存，不影响桌面端」。

## 改进

- **回合状态指示器收小一档**：原来的环偏大、粒子偏密，和后面的文字不在同一层级。现在环径 16px、粒子点更清晰，文案提到 13px，长回答滚动时不会再抢注意力。

- **安装包更小**：Codex 与 Claude 的运行组件改为按需下载，安装包不再内置这两份组件。在 Agent 详情里按需获取，下载前会说明来源与体积，装好即可使用。

## 升级说明

直接覆盖安装即可，本地会话、设置与凭据都不受影响。升级后在意的两条可以马上验证：点「去登录」只弹一次浏览器；WorkBuddy 的回答不会出现整段重复。
