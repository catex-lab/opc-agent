# OPC Agent v1.0.6

本版把「过程流怎么读、知识库怎么查、CLI 怎么收尾」三件事补齐，并修掉模型清单在
CLI 枚举为空时退回空手动清单的问题。

## 新增

- **过程流一行摘要**：一轮回答结束后，整轮思考、旁白与步骤会收成一行摘要，正文
  紧随其后，不再把一长串过程铺在回答前面。点摘要条可以展开全部思考、旁白和步骤，
  再点一次收起。
- **知识库逐 Agent「主动检索」**：每个 Agent 可以单独打开，默认关闭；打开后每轮最
  多自动检索 2 次，避免把无关会话都拖进检索。
- **知识库混合检索**：本地向量 + BM25 融合排序；本机没有向量模型时自动降级为纯
  关键词检索，功能不因此不可用。相近的重复片段会自动去重，群聊内容对本工作区可见；
  索引增加体积上限与清理入口（`/api/kb/prune`）。
- **模型清单不再空手**：CLI 没列出模型时仍会合并官方清单；qoder 家族以「未验证」
  角标呈现，可以先切过去跑一次确认，不再退回空的手动清单。

## 修复

- **CLI 超时按进程树终止**：连同子进程一起收，并留 5 秒有界收尾；Qoder 家族的超时
  放宽到 20 分钟，长任务不再被过早掐断。
- **bash 引号报错有提示**：工具输出里遇到引号导致的语法问题，会给出「换成单引号
  重试」的提示，不用自己去猜。
- **过程流关键步骤常驻**：展开后，写入、删除、权限、报错类关键步骤不会再被自动收
  起；手动展开过一次，这一轮就不再自动折叠。

## 需要注意

- **1.0.0 旧版首次仍需手动更新一次**：应用内更新从 1.0.5 之后才恢复正常。
- **主动检索默认关闭**：这是逐 Agent 的开关，需要到对应 Agent 的设置里打开。
- **校验口径**：验收主链已扩到 98 段，新增 5 条闸门。ZCode 缺失时会显式跳过并打印
  原因（不算通过）；claude/codex SDK 的平台二进制属于发版产物，闸门仍要求随包存在，
  缺了就是红。

## 升级方式

- 新安装或已在 1.0.5 及之后：应用内「检查更新 → 退出并重启」即可自动替换。
- 1.0.0 旧版：请手动更新一次，之后恢复正常。
- 会话数据保存在 `%APPDATA%\opc-agent`，覆盖安装不受影响。
