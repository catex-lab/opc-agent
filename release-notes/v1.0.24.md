# OPC Agent v1.0.24

这一版把 Agent 详情页的状态说明收成了一套统一规则：结论一行、证据一行，接入方式下面不再挂重复的灰色长句。所有接入的 Agent 都按同一套版式显示，以后新接的 Agent 也不会再各写各的。没有破坏性改动，本地会话、设置与凭据不受影响。

## 改进

- **状态说明不再一句话塞三件事**：以前每个 Agent 把「结论 + 限制 + 文件时间」拼在一行里，于是 WorkBuddy 那行会冒出「keyblob 最后更新 11/9」「（未校验）」这类看着像故障的旧信息。现在状态行先给结论（例如「在线 · 检测到本地登录态：当前账号」），证据和限制放到下一行小字；真实检测通过之后，这些提示直接收起，不会再拿旧时间冒充现在的事实。

- **接入方式只留结论**：详情页「接入方式」下面那段安装来源与协议细节（「DeepSeek Harness 桌面版（官网安装），通过 ACP（stdio JSON-RPC）接入」这类）已去掉，只显示「ACP 协议」「SDK 接入」。安装和下载信息本来就在同一页的获取卡片里，不必说两遍。

- **同一件事不再说两遍**：「还没做过真实检测」原来既让状态显示「未验证」，又在下面单起一行重复一遍，现在合并到状态行的次级提示里。状态仍如实显示「未验证」，不会假装在线。

- **对所有 Agent 生效**：WorkBuddy、DeepSeek Harness、Claude、Codex、各类 CLI 与 API Key 类 Agent 共用同一套文案规则；新增 Agent 只要走这套规则，就不用再各自拼句子。

## 升级说明

直接覆盖安装即可，本地会话、设置与凭据都不受影响。
