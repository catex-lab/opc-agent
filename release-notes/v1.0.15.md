# OPC Agent v1.0.15

本版把对话流打磨到「长回答逐字出现也不跳」：贴底跟随、首字占位、光标行与状态行等高、收尾线性追赶都落成稳定行为，工具轨迹也不再被折叠动画打断。另有两处新行为——上一轮没跑完会先问你，失败原因会随消息保留。没有破坏性改动，本地数据与升级路径不变。

## 改进

- **长回答不再跳动**：流式输出全程贴着底部，内容高度一变就即时跟随；第一个字到达前预留同等行高，回合末尾的光标行不再塌陷，状态行与操作行同高。收尾阶段此前 57.4px / 24.5px / 15.5px 的瞬时位移一并消除；最后一段改为 160ms 线性追赶，追完再撤光标。

- **工具轨迹不再反复折叠**：流式过程中轨迹段保持展开，新步骤只更新摘要行；回答中间插入工具时另起轨迹段，正文锚点跟着文本走。长回答滚动时不会被折叠动画打断。

- **过程更轻**：消息行与正文做了 memo 化，分段 key 改为稳定值，长会话的逐字渲染与滚动开销下降。

- **HTTP 直连型 Agent 记得上下文**：会带上最近 8 轮、约 2000 token 的对话历史，换会话不必每次重述。

## 新增

- **上一轮没跑完，先问你**：续接悬空 CLI 回合前弹出流内确认卡；「问不出去」的情况也会落到消息流里，不再静默消失。

- **失败原因看得见**：Agent 报错不再只留一句「执行失败」，具体原因随消息落库，重开会话仍然在。

## 安全与隐私

- 源码示例中的邮箱与本机路径改为通用占位，README 截图夹具换成纯虚构演示数据。历史提交里的旧内容不在本次清理范围内，仓库地址与安全联系邮箱不变。

## 需要注意

- 无破坏性改动，取值与数据契约不变；会话数据仍保存在 `%APPDATA%\opc-agent`，覆盖安装不受影响。

- 更新清单与代码包仍走签名校验，升级方式与上一版一致。
