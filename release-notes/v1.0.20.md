# OPC Agent v1.0.20

这一版把「多 Agent 团队」从一句话的比喻补成真本事：并行不再互踩、任务可以排班、会话可以换人接力、审批可以在手机上完成。另外，通讯录新增「手动添加 Agent」，名单之外的本地 CLI 也能接进来。没有破坏性改动，本地数据与升级路径不变。

## 群聊执行

- **并行隔离（worktree）**：群聊头部新增「隔离」开关。开启后本轮每个成员在独立的 git 检出里执行，结束后逐个把改动汇合回主工作区；发生冲突时立即停止自动汇合，改动保留在分支和检出目录里由你裁决。全程绝不自动 push；工作目录不是 git 仓库时会说明原因并退回共享目录。
- **带队模式**：编排模式新增「带队」。主控先把任务拆成结构化的分工计划（谁、做什么），各成员并行执行自己那份，最后由主控整合汇总。主控给不出可解析的分工时自动退化为广播，不会瞎猜。

## 定时任务

- **会话可排班**：单聊「⋯」菜单与群设置面板新增「定时任务」。到点把一条指令当作普通消息投进会话，产出按既有消息回流——权限门照卡、记录照落。支持 cron 表达式与常用预设，保存前可预览接下来几次的触发时间；每天超过 6 次的高频排班会被拒绝（每轮都是真实调用，高频请用工作流脚本）。仅在应用运行期间调度，错过的时间点不补跑，同一任务上一轮没跑完时本轮跳过。

## 会话接力

- **跨 Agent 转交**：一对一聊天新增「转交给…」。选一个接手人，他会带着此前对话的摘要继续；你的下一条消息由他接手。转交可逆，摘要只注入一次，不反复占用上下文。

## 手动接入 Agent

- **手动添加 Agent**：通讯录「+」菜单新增入口。填启动命令、参数、输入/输出方式，检测通过即可接入——进程不经过 shell 拉起；输出支持纯文本与 JSONL 事件两种协议，JSONL 支持续接令牌。检测（零成本解析）与试跑（一次真实调用）分开，不会为了「确认一下」就烧额度。自定义条目在通讯录独立分组，右键可编辑、可移除，移除只删接入声明不动本机文件。

## 远程审批

- **人不在电脑前也能批**：设置 → 权限门禁新增「远程审批」。配置群机器人 webhook 后，越权请求会外发成聊天卡片，手机上点链接放行或拒绝。卡片只带工具名与输入摘要（命中敏感内容自动隐去）；审批链接一次性有效，应用内的审批浮层同样可以答复，谁先算谁。应用不做云端中继：webhook 与审批链接的对外地址都由你自配。

## 项目任务

- **任务可指派**：项目任务新增指派人与改派。票与成员解耦——改派只是换人，状态机跟着票走；指给一个还没安装的 Agent 也是合法的排班。

## 界面与体验

- 群聊「⋯」菜单、群设置面板、项目详情、设置页权限区随上述功能同步更新，全部走既有设计令牌与键位约定；中英文文案同步补齐。
- 在一个会话还在回复时直接发送新消息，现在是「打断并追加」：上一轮立即中止（部分产出保留），新指令照常走发送链，不再被「先点停止」挡回去。

## 修复

- 修复「停止」后立刻在同一会话重发时，旧一轮的收尾可能拆掉新一轮停止把手的竞态（表现为停止键失效、气泡仍在长字）。

## 需要注意

- 并行隔离与定时任务只在会话绑定了工作目录时生效；定时任务仅在本应用运行期间调度。
- 远程审批依赖你自配的 webhook 与网络可达性；未配置时一切行为与之前完全一致。
