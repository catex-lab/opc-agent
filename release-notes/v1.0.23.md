# OPC Agent v1.0.23

这一版把第三方许可声明补齐、让 Claude SDK 改为自装（不再随包分发），并修正过程面板的三处交互和权限设置的危险档提示。没有破坏性改动，本地数据与升级路径不变。

## 安装与依赖

- **Claude SDK 改为自行安装**：Claude SDK 本体不再随安装包分发。如果你要用 Claude Agent，在它的 Agent 详情里会看到安装命令，按提示装好后无需重启即可使用；没装时状态会如实显示「SDK 本体未安装」，不会先报可用、到发消息时才失败。

- **许可声明随包可查**：完整的第三方许可清单现在随安装包分发，在「关于与隐私」里可以直接打开查看。此前安装包内没有这份文本，第三方组件的署名义务落了空。

## 修复

- **过程面板拖动更听话**：最小化胶囊拖动后不再一松手就切形态，真的拖到屏幕右缘才吸附；落点提示从覆盖大半屏幕的虚线框改成跟随面板的小标签；吸顶形态紧贴会话头下边缘，不再悬在半空。设置弹窗打开时，吸顶面板也不会再浮到弹窗上方。

- **危险权限档不再显示成绿色**：权限设置里的「全放行」档此前显示为英文原词配绿色小字——绿色暗示「安全」，用来标跳过所有权限确认的档位是误导。现在显示为中文名「全放行」和红字危险提示。

- **隐私说明不再说绝对话**：不再写「全部数据只存在本机」，改为如实说明：对话内容不会离开本机，但更新检查、模型目录、组件下载和生图会发起不含对话内容的请求。

- **许可信息更正**：第三方清单里 CodeBuddy CLI 的许可由「无法查证」更正为 MIT。

## 升级说明

直接覆盖安装即可，本地会话、设置与凭据都不受影响。
