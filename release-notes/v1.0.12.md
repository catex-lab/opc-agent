# OPC Agent v1.0.12

本版把这一轮界面细节落地到真实组件，同时修复 WorkBuddy 的默认模型问题。没有破坏性改动，本地数据与升级路径不变。

## 新增

- **知识库与扩展列表的加载骨架**：冷启动不再只看到一句「正在读取索引状态…」的灰字。知识库骨架按首屏真实结构铺检索区与 5 个索引概览卡，扩展列表铺 4 行条目；加载完成即交回真实内容，深色主题同一套令牌。

- **知识库弹层的键盘可用性**：Esc 直接关闭、打开后焦点移入面板、Tab 只在面板内循环，屏幕阅读器能通过标题读到弹层名称。

- **窄窗下的工作区抽屉**：窗口宽度 ≤900px 时，打开工作区不再把内容压成一条竖列，改为带遮罩的浮层抽屉；遮罩与阴影跟随浅色 / 深色主题，关闭后回到原会话。

## 改进

- **知识库首屏先给检索**：检索区置顶，范围、本会话、主动检索、回填与重建收进默认收起的「知识库设置」；分区说明字号 11→13px，对比度提高到 5.10:1。

- **阅读行宽与答案排版**：一轮回答的正文列宽从 800 收到 720，更接近阅读栏宽。

- **过程流摘要改为结论口径**：先写「改了 N 个文件 / 读完 N 个文件」，再给成功或失败；短于 3 秒的步骤不再标耗时，工具耗时统一写成「工具 30.0s」，关键步骤改用形状标记而不是彩色。

- **验证与文件核对合并成一行**：默认收起，展开后才读逐条细节，面板不再被两段相近的信息占满。

- **状态点统一语义**：所有出现位置都是「形状 + 文字」，在线 / 待处理 / 离线靠形状区分，颜色只做辅助，不再有同一种圆点表达两种状态。

- **会话头与侧栏**：窄窗下知识库入口退化为单色图标并保留 aria-label，名字截断后仍能读回全名；侧栏六栏宽 70→74、导航标签常驻，并增加全局知识库入口。

- **设置与关于**：分区眉标字号与对比度提升到硬门槛（≥4.5:1），关于页补齐分区图标；资料页内容宽度收到 560。

- **圆角与遮罩收敛到令牌**：圆角统一为四档（面板 14 / 浮层 12 / 卡片 10 / 小控件 8）；知识库遮罩改用主题令牌，深色下不再是一块固定黑。

## 修复

- **WorkBuddy 默认模型改回 SDK 的 Auto**：默认不再回落到已下线的 `claude-sonnet-4`；模型接口在 SDK 清单不可用时只给 Auto，不再展示 `claude-sonnet-4 / claude-opus-4` 这些实际跑不了的假选项。

- **旧会话的失效模型名不再等到调用时报错**：会话里存着已下线的 SDK 模型名时，发请求前回退为「不指定」，交给 SDK 自己的默认模型。

- **知识库重建改为行内确认**：确认条常驻「不影响聊天记录」的提示，不再跳出独立对话框。

## 需要注意

- 从 1.0.11 起自动更新链路才完整；1.0.10 及更早仍需手动覆盖安装一次（交接进程自锁的修复只对自带该脚本的版本生效）。这一次 1.0.11 → 1.0.12 是第一次用于真实验证应用内自动更新。

- 若你曾在 WorkBuddy 会话里显式选过已下线的旧模型，本版会回退到 Auto；需要固定型号时请在会话里重新选择。

- 会话数据保存在 `%APPDATA%\opc-agent`，覆盖安装不受影响。
