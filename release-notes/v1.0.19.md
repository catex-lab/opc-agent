# OPC Agent v1.0.19

这一版把「账号和模型信息到底可不可信」讲清楚，并让同一个 Agent 可以保存多份账号随时切换。凭据能一键发起一次真实只读请求验证，换 Key / 换账号后模型清单与账号状态会一起刷新。没有破坏性改动，本地数据与升级路径不变。

## 凭据与账号

- **凭据可以真校验**：设置里新增「校验凭据」，用一次最小只读请求确认 Key 是否真的可用，并区分「无效或无权 / 触发限流 / 该服务没有只读端点 / 上游异常」，还能列出服务端返回的可用模型。结论与「来源 / 探测时间 / 是否已校验」一起显示；没有真实请求通过之前，界面不会把本地快照说成已验证的事实。
- **一个 Agent 多个账号**：可以为同一家服务保存命名账号（例如「个人」「工作」），一键切换、单独删除。切换时当前生效的 Key 与网关地址一起换掉，旧值不残留；只存一份账号时仍沿用原来的文件格式，老版本读取不受影响。
- **换 Key 后界面跟着刷新**：保存、清除凭据、切换账号、修改环境变量或手动刷新模型目录后，模型清单、账号状态与各 Agent 的模型列表一起重新读取，不再留着上一份缓存里的旧模型。

## 信息与隐私

- 账号、凭据与模型信息统一标注「来源 / 探测时间 / 是否已校验」：读到本地快照不再被当成实时事实，没探测到或已过期的状态会明说。
- 输入框回显本轮真正生效的模型，而不是发起前选中的那个；切换会话时迟到的事件不会串改当前输入框。
- 「关于与隐私」页重排为一屏一主角、三层递减的信息结构，隐私说明与第三方许可入口更好找。
- 英文界面补齐错误兜底页与自定义 Agent 的编辑 / 删除提示，不再混入中文。
- 运行日志不再原样记录 CLI 续接令牌和登录授权链接，改成不可还原的短指纹；排查时仍能对照「是不是同一条」。
- 启动 Agent CLI 时不再继承宿主注入的「全局关闭 TLS 证书校验」设置，避免子进程联网抓取时跳过证书校验。
- 本机 `.env` 凭据文件明确排除在版本库之外；全量密钥扫描遇到读不到的文件或自身出错时不再报「通过」。

## 修复

- 点「停止」后思考过程块不再一直转圈：停止时同时收口过程块的流式状态。
- 发版时不再因中间产物被提前清理而漏掉自动更新清单所需的签名信息；安装包内容与体积不变。
- 自动验证某个项目时只采用名字合规的脚本，执行前还会再校验一次整条命令。
- 「关于」页与自定义 Agent 弹窗里几颗图标按设计档位收小，不再挤占旁边的文字。

## 需要注意

- 无破坏性改动；新增行为都沿用原有偏好与数据契约，覆盖安装不受影响。
- 更新清单与代码包仍走签名校验，升级方式与上一版一致。
