# OPC Agent v1.0.22

这一版解决「长任务跑到一半被掐断」的问题，并把耗时的显示口径统一了。没有破坏性改动，本地数据与升级路径不变。

## 修复

- **长任务不再中途被杀**：以前 CLI Agent（Pi / Codex / Kimi 等）的一条指令有 8 分钟的硬上限，跑 20 多步改几个文件的任务很容易在 8 分钟整被终止（报「超过 480 秒仍未完成」）。现在改为看「还有没有动静」：只要 Agent 还在产出就继续跑，连续 8 分钟没有任何输出才会终止（并明说「可能卡住」）；整个回合的失控兜底放宽到 60 分钟。

- **后台服务更皮实**：后端从界面进程里拆了出来。界面出问题不影响正在跑的 Agent；后台服务若意外退出，界面会明说「核心服务重启了一次，正在恢复」并自动拉起，进行中的回合如实记为「中断」，不假装完成。

- **本机接口加锁**：应用的本地接口现在带随机令牌校验，每次启动换新令牌，别的本地进程无法直接调用你的会话接口。

## 改进

- **耗时口径统一**：不满 1 分钟显示「N 秒」，满 1 分钟显示「M 分 S 秒」——消息头部、状态行、用量小字都是同一套写法，不再混着「63.7s」和「8 分钟」。

- **状态环暗色模式可见**：回合状态指示器的 12 颗粒子改为等亮度全亮，暗色模式下与正文同样清晰。
