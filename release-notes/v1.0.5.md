# OPC Agent v1.0.5

本版修掉「更新下载完成、却装不上」的阻塞问题。

## 修复

- **应用内更新可以真正装上了**：在 1.0.2 及之后版本里，检查更新会显示「已下载，
  重启后生效」，但点「退出并重启」会弹出 `ENOENT … app-1.0.4.asar`，更新装不进去。
  本版改掉暂存包的保存方式，并在交接前重新核对文件是否存在、体积与摘要是否与清单
  一致；任何不符都会给出中文提示、回到可重新下载的状态，而不是把英文异常甩到界面上。
- **暂存目录自动清理**：升级成功后不再留下旧的下载残留。

## 升级方式

- **1.0.4 及更早版本**：应用内更新这一次装不上，请手动升级 —— 退出应用，用
  `OPC-Agent-1.0.5-x64-full.zip` 解压覆盖安装目录即可。升级到 1.0.5 之后，应用内
  更新恢复正常。
- **新安装 / 已到 1.0.5**：后续版本恢复应用内「检查更新 → 退出并重启」自动替换。
- 会话数据保存在 `%APPDATA%\opc-agent`，覆盖安装不受影响。
