# OPC Agent v1.0.18

这一版主要补齐标题栏 logo 折叠入口的无障碍语义，并让安装包构建更快、不再把数 GB 的中间产物留在磁盘上。没有破坏性改动，本地数据与升级路径不变。

## 无障碍

- **标题栏 logo 折叠入口可读可操作**：补上 `role=button` 与随状态更新的 `aria-expanded`，键盘 Enter / 空格均可切换并拦掉空格滚动，读屏能读出「展开 / 收起」当前状态；当前页不可收起时仍保留可聚焦与可读状态，不会变成无标注的空格子。

## 安装包

- **构建提速并自动清理**：7z 压缩级别固定，构建结束即删除临时目录，不再把 2 GB 级中间产物留在磁盘上。安装包内容与体积不变。

## 需要注意

- 无破坏性改动；新增行为都沿用原有偏好与数据契约，覆盖安装不受影响。
- 更新清单与代码包仍走签名校验，升级方式与上一版一致。
