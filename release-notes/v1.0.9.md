# OPC Agent v1.0.9

本版把升级交接补牢，并把关于页压成清爽的三段式。1.0.8 升级失败留下的红字会在本版之后按版本自愈。

## 修复

- **升级交换加固**：退出后仍有残留实例握着 `app.asar` 时，不再直接撞 `EBUSY` 就放弃。交换前会等安装目录里的进程退出（最多 20 秒），只对「更新开始前就已存在、且映像路径在安装目录内」的残留做定向结束，绝不按进程名全局杀；锁重试预算从 20 秒提到 60 秒，失败红字会点名实际持有者。成功与失败都会清掉残渣，旧的失败记录按版本自动消解。
- **更新说明正常渲染**：应用内更新说明不再原样显示 Markdown 的井号、星号和转义反斜杠，改为收进约 480px 宽的弹层，标题、列表与加粗都按结构渲染。深色主题下弹层外加一层 12% 的极淡遮罩，浅色保持不加遮罩。

## 改进

- **关于与隐私页三段式**：版本信息压成一行（名称、版本、Electron / Node / 平台架构），更新区只保留状态与动作、整体高度约 217px，隐私声明改成三张常驻合规卡（不收集信息 / 只发给你自配的模型服务商 / 永久免费且无广告）。窄屏下三张卡自动落成单列，不横向溢出。

## 需要注意

- **1.0.7 及更早版本升级仍可能受旧 helper 影响**：旧版应用内自带的是旧交换逻辑，遇到残留进程仍可能直接失败。若升级失败，请先完全退出应用（托盘退出，并在任务管理器确认没有 `OPC Agent` 进程）再重试；仍不行就用手动包覆盖。
- 1.0.8 仍携带旧的交换 helper，所以从 1.0.8 升到本版同样可能受残留进程影响；加固逻辑要从本版开始才对后续更新生效。
- **1.0.0 旧版**内置的还是更早的更新公钥，首次仍需手动更新一次。

## 升级方式

- **1.0.8**：设置 → 关于与隐私 → 检查更新 → 下载更新 → 退出并重启，走应用内自动替换。若被残留进程挡住，先完全退出应用再重试，或改用手动包。
- **1.0.7 及更早（含 1.0.6、1.0.5）**：建议手动升一次 —— 完全退出应用（托盘退出，任务管理器确认没有 `OPC Agent` 进程），用本 Release 的 `OPC-Agent-1.0.9-x64-full.zip` 解压覆盖安装目录即可；也可以只把 `resources/app.asar` 换成 Release 里的 `app-1.0.9.asar`（更省流量）。
- **1.0.0 旧版**：内置公钥与当前签名不匹配，需先按上一条手动更新一次。
- 会话数据保存在 `%APPDATA%\opc-agent`，覆盖安装不受影响。
