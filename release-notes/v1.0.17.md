# OPC Agent v1.0.17

这一版主要解决「点了发送却半天没反应」：Agent 冷启动的探测不再挡在首字前面，群聊不再被某个慢成员挂住，断线重连也不会再出现重复正文。同时腾讯 SDK 与 Claude SDK 支持 token 级正文增量，首字更早出现。没有破坏性改动，本地数据与升级路径不变。

## 更快看到第一个字

- **探测移出首字路径**：CLI 冷启动只做必要的同步定位，版本、凭据、网络探测转到后台回填；每个探测都有硬超时与总预算，超时按「状态未知」处理，不会静默判为可用。

- **首轮探测更克制**：窗口空闲 5 秒后才开始全量探测，并发降到 2，不抢首条消息的资源；手动触发的探测不受这个延迟影响。

- **群聊先连上再检查成员**：成员探测移到连接建立之后，前端不再长时间零帧；某个成员太慢也不会拖住整轮对话。

- **Codex 立刻回应**：收到 turn.started 就显示「思考中」，即使正文还没到，也不会看起来像卡死。

- **token 级流式**：腾讯 SDK 与 Claude SDK 的正文与思考内容按增量推出；子 Agent 的输出与主回答分开处理，不会互相覆盖。

## 稳定性

- **重连不重复正文**：断线恢复时不再回放已经覆盖在快照里的内容。

- **成员运行正常收尾**：结束时同时关闭当前块与整轮运行，活跃清单不会残留，重连流也会正常关闭。

- **过期模型目录不挡调用**：有旧缓存先返回、后台刷新；只有首次安装才同步等待枚举。

- **Codex 权限档变更后新建线程**：续接会沿用创建时的权限档，现在检测到变更就丢弃续接令牌、强制新建，避免权限错位。

## 安全

- **IPC 来源校验**：终端等 31 个入口统一校验「主窗口 + 主 frame + 窗口 origin」，只允许应用自己的页面调用。

- **开发服务器只监听回环**：并收掉宽松的 Host 放行，接口不再对外暴露。

## 界面

- **折叠入口换位置**：二级栏折叠钮从导航条底部移到标题栏 logo 格，整格可点，键盘 Enter / 空格也能切换，右下角箭头提示当前是收起还是展开。

- 已知取舍：logo 这一格改为不可拖动，格内无法用鼠标拖动窗口或双击最大化；标题栏其余拖拽区与三个窗口按钮不变。

## 需要注意

- 无破坏性改动；新增行为都沿用原有偏好与数据契约，覆盖安装不受影响。
- 更新清单与代码包仍走签名校验，升级方式与上一版一致。
