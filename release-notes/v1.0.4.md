# OPC Agent v1.0.4

本版把三条界面工作线与整包分发体验一起收口。

## 变更

- **会话顶栏更紧凑**：单聊与群聊共用同一套宽度断点。窄窗口下标题仍保有可读宽度，
  知识库入口收成图标，群聊的成员数不再被过长的群名挤掉。
- **过程流一轮只留一条摘要**：思考、工具调用与旁白合并进同一张轨迹卡，轮次结束自动
  收拢；没有收到真实结束事件的步骤标为「结果未回传」，手动展开后不会被再次自动折叠。
- **扩展矩阵列对齐**：能力矩阵改为三列固定网格，两条分组共用列定义，组头与条目左边界
  对齐；窄窗口自动降为单列。

## 修复

- **完整包可直接用资源管理器解压**：`OPC-Agent-1.0.4-x64-full.zip` 不再出现「压缩(zipped)
  文件夹无效」，双击「全部解压缩」即可（1.0.3 起修复，本版沿用）。

## 升级方式

- 已安装用户：应用内「检查更新」会读取 `latest.json` 并只替换代码层，无需重装。
- 手动安装：下载 `OPC-Agent-1.0.4-x64-full.zip`，退出应用后解压覆盖安装目录即可；
  会话数据保存在 `%APPDATA%\opc-agent`，不受影响。
