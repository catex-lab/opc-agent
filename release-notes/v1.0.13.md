# OPC Agent v1.0.13

本版处理两处界面观感问题，并把首条指令的等待挪到打字期间。没有破坏性改动，本地数据与升级路径不变。

## 改进

- **左侧导航栏回到纯图标栏**：去掉图标下方的 10px 文字标签，栏内只剩图标。每个入口仍保留可访问名称与悬停提示（鼠标停上去显示「聊天 / 项目 / 通讯录 / 扩展 / 知识库 / 设置」），不会变成没有语义的图标墙。

- **导航图标边缘更清晰**：图标改为按图标集自身的 24px 尺寸渲染（此前缩到 20px），描边从折算后的 1.67px 回到整 2px，浅色与深色下边缘都不再发虚；图标中心与入口间距不变。

- **首条指令更快**：打开会话时就在后台预热对应 Agent 的 CLI 子进程，把冷启动的等待挪到用户打字期间；应用刚启动、探测还没完成时，也会在探测就绪后补上预热，并按会话当前的权限档匹配。实测首条指令中位耗时 7.2 秒 → 1.0 秒。

- **每轮记忆装配更省**：记忆上下文按文件的修改时间与大小做快照缓存，重复轮次里不再反复读盘与重复估算（单轮 10~16ms → 2~3ms）。

## 修复

- **亮色在线状态点恢复浅绿**：此前圆点与状态词共用墨绿色，8px 实心点在浅色页面上偏暗、与整页不协调；现在圆点单独用浅绿令牌，深色模式保持原观感。状态区分仍只靠形状（在线实心 / 非在线 1.5px 空心环），颜色只做辅助。

## 需要注意

- 状态点改色只影响圆点本身，「在线」「待处理」等状态文字与其它页面保持原样。

- 会话数据保存在 `%APPDATA%\opc-agent`，覆盖安装不受影响。
